# ZKEY site

TanStack Start frontend for ZKEY → KEY → private ZEC.

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
- Solana web3.js

## Development

Requires Node.js (or Bun).

```sh
cp .env.example .env   # fill placeholders — never commit .env
npm install            # or: bun install
npm run dev
```

See the repository root README for architecture, economics, and required secret names.
